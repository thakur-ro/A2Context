# Test whether citation examples influence the IDs in a reply

In the original PaperQA requests, opaque keys label source passages. Separate keys appear in the instructions showing how to format citations. The original provider replies used at least one example key in each of the five sessions. Later application formatting may remove a key. The provider response is the outcome under investigation.

Before running the intervention, fix all five final requests and three seeds (11, 29 and 47). At temperature 0.5 and a 512-token limit, send each original request twice and one edited request. In the edit, replace every mention of each example-only key in the instruction suffix with a deterministic new key of the same prefix and character length. Keep the passages, their keys, question, instructions and sampler otherwise fixed. Check that neither new key appears anywhere in the original. Shuffle arm order within each request and seed. Generate no tool calls or external actions.

Count original example keys, renamed example keys and actual passage keys appearing in parenthetical citations. A paired switch means the original and unchanged repeat both used an original example key, and the edited reply used the corresponding replacement. Report all arms and failed calls. This is a source-specific test of citation behavior on five previously inspected development questions and one local model. A copied identifier alone cannot establish that its accompanying sentence was wrong.

## Results

We also checked what a user would have read in the original five sessions. Seven example-only citations became empty parentheses in PaperQA’s printed answers, including at least one in every answer. For each match, the same 64 preceding characters identify the passage in the provider reply and the application log. For example, the provider ended the first answer with “a clear path for accurate attribution. (pqac-d79ef6fa)”. The application printed “a clear path for accurate attribution. ()”. This establishes a visible missing reference. [Matched excerpts, offsets and application log digests](displayed-citations.json)

All 45 requests completed. Both unchanged runs cited an original example key in 14 of 15 question–seed pairs. The edit produced its corresponding replacement in all 14. In the remaining pair (question 1, seed 29), neither unchanged run cited an example key, and the edited run did. All 45 replies also cited at least one actual passage key. No unchanged reply cited a replacement, and no edited reply cited an original example key. The two unchanged runs returned identical citation sets at every seed.

On these requests, changing the formatting examples changed which identifiers the model used as citations. The visible product finding points to the key in the prompt and reply. Establishing an effect requires the separate experiment. The five questions share one application and model, so the 15 pairs cannot estimate prevalence in other systems. The outcome counts provider replies before PaperQA formats them for the reader.
