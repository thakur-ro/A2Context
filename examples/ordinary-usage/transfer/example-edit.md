# Does the worked example supply words to the retrieval answer?

The frozen LlamaIndex feed missed a response that mentioned water and the sky when the user asked about context attribution. Those words occurred only in the shipped worked example. Before generating new replies, fix all five original requests, seeds 11, 29 and 47, temperature 0.5 and a 512-token limit. Run each request unchanged twice and with one edited example. Keep the request after the example boundary byte-identical, including the retrieved sources and user question. Keep the source numbers, colors and structure of the example. Replace sky with lamp, water with wax and wet with soft inside the example only. Preserve capitalization. Verify that the original and replacement subject words occur nowhere in the retrieved sources or real question before including a request.

Count a reply as using the example topic when it contains the whole word water or sky. Use wax or lamp for the replacement topic. Report each arm, unchanged-repeat agreement and strict paired switches where both unchanged replies use the original topic and the edited reply uses the replacement without the original. Check the surviving excerpts for coincidental word use. Retain all failures and report seed pairs within their five questions. This follow-up tests source influence on wording. It uses a previously inspected cohort and cannot establish that changing the example improves answer quality.

## Result

All five requests qualified and all 45 replies completed. The original and unchanged repeat produced identical topic-word sets in all 15 pairs. Both mentioned the original topic in two pairs. Editing the example removed the original topic in both. In two *other* pairs the edited answer introduced both lamp and wax. No unchanged answer used either replacement word. The registered strict switch count was **0 of 15**.

The excerpts support a narrower conclusion. On question 1 at seed 47, the edit produced a claim about a red lamp affecting wax softness. On question 2 at seed 11, the edited reply discussed conditions for wax softness when asked about sidecar memory. The replacement concepts reached the answer under those conditions. The same-seed substitution observed with PaperQA’s citation IDs did not reproduce here. The original pilot reply that prompted the study used water and sky. None of the six unchanged follow-up replies to that particular question reproduced the topic. [Trial outcomes and matched excerpts](example-edit-results.jsonl)
