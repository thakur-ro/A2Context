# Do the fixed alarms transfer to human-labeled questions?

Use the official SQuAD 2.0 development set. Its human-authored questions include adversarial unanswerable questions about a supplied Wikipedia paragraph. The file has SHA-256 `80a5225e94905956a6446d296ca1093975c4d3b3260f1d6c8f68bc2ab77182d8`. [Dataset and license](https://rajpurkar.github.io/SQuAD-explorer/) · [Development file](https://rajpurkar.github.io/SQuAD-explorer/dataset/dev-v2.0.json) · [Rajpurkar et al., 2018](https://aclanthology.org/P18-2124/)

In original file order, take the first 24 distinct article titles with a paragraph containing at least one question of each answerability class. Use the first qualifying paragraph for each title and the first question of each class within it. Keep all 48 questions. Score the raw paragraph alone in the numbered passage slot. The title, question ID, answer spans and human label stay outside the scoring input. Every pair shares the same context and differs in its question.

Apply the exact three previous scoring functions, Qwen checkpoint and prompts. Raise an alarm for scores strictly above −5.487243987294204 for the instructed abstention, −2.1161061263074745 for negative maximum BM25, and 0.21515066597560203 for the forced-choice probability of NO. No retuning. The pinned source of these cutoffs has SHA-256 `bf15081c3e7bf0f9667cad3a6335f45fe5f8383c853ffd7f011a1df71caf24ce`. [Calibration and thresholds](../scores.json)

Treat SQuAD's `is_impossible` as the positive class. Report true positives, false positives, false negatives and true negatives, plus sensitivity and specificity. Record ties and how often the unanswerable question scores higher within its paragraph. Record model forward passes, input tokens and elapsed scoring time. Both model scores use one forward pass per question. There is no free generation. Publish identifiers, digests, labels and scores. Keep the text outside the repository.

The calibration domain contained nine retrieved passages per question and varied the source inventory. Here every question has one human-selected paragraph. BM25 estimates document frequencies from the supplied passages, so with one paragraph all matching terms have the same inverse document frequency. The same cutoff now operates on a different score distribution. The balanced sample cannot estimate alert rates in production. This is a public development set and its exposure during model training is unknown.
