# Does removing reviewed supporting evidence change an answer more often than a control edit?

Use the 12 previously reviewed questions and their original nine-passage inventories. One AI reviewer recorded sets of passages that jointly support a reference answer or another reasonable answer. No human adjudicated those sets. Each set is one way the reader could establish an answer. [Review method](../annotation.md) · [Frozen annotations](../labels.json) · [Question and article credits by row](../../data-credits.md#article-sources-by-dataset-row)

For each question, keep only sufficient sets whose members all appear in the original nine passages. Enumerate the smallest groups of slots that intersect every one of those sets. A control must remove the same number of slots. It can use only passages absent from every recorded sufficient or uncertain set in the full ten-passage review, including incomplete sets. Exclude a question if it has no complete sufficient set or too few eligible control slots. Keep exclusions in the manifest.

Consider each minimum target group and each ordered assignment of eligible control slots to its members. Using one-based slots and target slots in ascending order, minimize the sum of absolute differences in passage word counts, then the sum of absolute differences in slot positions. Count words by whitespace splitting the unmodified title, newline and passage text. If several assignments tie, choose the lexicographically earliest vector of target slots, then of control slots. Record both residual sums and the number of tied assignments. Actual prompt token lengths may still differ.

Generate one greedy answer per included question in each of three conditions, in order: original, target edit and matched control edit. Keep all nine numbered slots, replacing only the selected title and text with the exact string `[passage omitted]`. Keep the pinned Qwen checkpoint, QA system instruction, question, chat template and 48-token limit. Save the exact decoded text or truncated prefix, stop reason, prompt tokens, generated token count including any end token, and elapsed scoring time. No free-form judging or external calls.

Primary counts use only questions where all three outputs reach an end token. Record target-only, control-only, both and neither for any exact change from the original answer. Report completed exact abstentions after stripping surrounding whitespace (`UNKNOWN`, case sensitive) and case-folded whole-token reference-alias matches per condition. Retain missing measurements for truncated answers. Also report when target and control give identical completed answers. An alternative supported answer or a synonymous rewording may fail the alias check. A change in text establishes sensitivity to this edit on this input. The experiment reuses reviewed questions and does not independently validate a predictor of model behavior.
