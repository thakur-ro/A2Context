# Credits

## Context inspection and replay

Victor Klee studied the length of a union of intervals in 1977. The source-boundary check applies an endpoint sweep to UTF-8 byte ranges in each JSON field, tracking distinct source IDs over those intervals. [Klee, *The American Mathematical Monthly*](https://doi.org/10.1080/00029890.1977.11994336)

- Giga Chang’s `context-render` informed the use of named context sources and cross-session views. It is an independent project for Claude Code. [context-render](https://github.com/gigayaya/context-render)
- Benjamin Cohen-Wang, Harshay Shah, Kristian Georgiev, and Aleksander Mądry introduced ContextCite, a related method for attributing generated statements to context. NexusWeave’s replay tests user-selected edits against recorded workflow decisions. [ContextCite, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/adbea136219b64db96a9941e4249a857-Abstract-Conference.html)
- Stefan Heimersheim and Neel Nanda describe how to apply and interpret activation patching. Their guide informed the decoder-block swaps and controls in the instrumented examples. [How to use and interpret activation patching](https://arxiv.org/abs/2404.15255)
- Mor Geva, Jasmijn Bastings, Katja Filippova, and Amir Globerson use interventions on attention edges to study information flow. Their work informs the source visibility probe. AttriBoT is a related implementation for efficient leave-one-out context attribution. [Geva et al., EMNLP 2023](https://aclanthology.org/2023.emnlp-main.751/), [AttriBoT, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/2aab664e0d1656e8b56c74f868e1ea69-Abstract-Conference.html)
- Marc Lipsitch, Eric Tchetgen Tchetgen, and Ted Cohen describe negative controls for probing bias. NexusWeave adapts that experimental idea by comparing a target edit with an edit expected to leave the decision unchanged. [Negative Controls, 2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC3053408/)
- Aaron Mueller’s analysis of independently sufficient causes motivated the synthetic two-source dispatch experiment. Peter Hase and colleagues tested limits on using localization to select model edits. [Mueller, 2024](https://arxiv.org/abs/2407.04690v1) · [Hase et al., NeurIPS 2023](https://arxiv.org/abs/2301.04213v2)
- Marco Tulio Ribeiro, Tongshuang Wu, Carlos Guestrin, and Sameer Singh developed CheckList for behavioral testing of NLP models. It provides a comparison for the declared-target experiments. [CheckList, ACL 2020](https://aclanthology.org/2020.acl-main.442/)
- Dongyu Ru and colleagues developed RAGChecker. Its claim-level diagnostics provide a comparison for evaluating the public passage edits. [RAGChecker, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/27245589131d17368cccdfa990cbf16e-Abstract.html)
- Shayne Longpre and colleagues studied answer substitution in QA contexts. Their method is related to the numerical edits in the journal experiment. [Entity-Based Knowledge Conflicts in Question Answering](https://aclanthology.org/2021.emnlp-main.565/)
- Wassily Hoeffding’s inequality supplies the bound used for reported replay intervals under independent sampling. The paired-edit test uses the four conditions of a two-factor design. [Hoeffding, 1963](https://doi.org/10.1080/01621459.1963.10500830), [NIST factorial experiment definition](https://www.itl.nist.gov/div898/handbook/glossary.htm)

R. Thomas McCoy, Ellie Pavlick and Tal Linzen studied lexical heuristics in natural-language inference. The indirect activity study includes lexical overlap as a comparison rule. [Right for the Wrong Reasons](https://aclanthology.org/P19-1334/)

The [scoping review](docs/research-review.md) compares the sidecar workflow with TRACE, REFLECT, LangSmith Insights, SentinelRCA, and Langfuse. The README structure uses [Transformers](https://github.com/huggingface/transformers) as a reference for showing a runnable result near the top.

- The routing comparison draws on research into tool-set changes by Ella Rabinovich and Ateret Anaby-Tavor. BFCL and the hidden-state study by Eric Yeats and colleagues provide benchmark and probe comparisons. [Function-calling robustness](https://arxiv.org/abs/2504.00914v1) · [BFCL](https://proceedings.mlr.press/v267/patil25a.html) · [Tool-error probes](https://arxiv.org/abs/2608.27750v1)
- Jaineet Shah’s Causal Agent Replay implements context interventions and downstream replay. Egor Pakhomov and Erik Nijkamp describe controls for attributing changes to history. Changran Xu, Zeju Li and Qiang Xu study observational evidence of memory use. We compare their methods in the [scoping review](docs/research-review.md). [CAR](https://arxiv.org/abs/2606.08275v1) · [History attribution](https://arxiv.org/abs/2611.05650v1) · [MemUse](https://arxiv.org/abs/2611.01718v1)
- The travel and watchlist studies use the BFCL team’s public multi-turn tasks, function schemas and in-memory TravelAPI and TradingBot simulators. The reproduction script verifies the pinned Apache-2.0 sources and notices. [Study and upstream credits](examples/bfcl-transfer/README.md#reproduce) · [Source manifest](examples/bfcl-transfer/sources.json) · [Watchlist protocol and reproduction](examples/bfcl-transfer/mlx/watchlist/README.md)
- Alexander Kovalenko and Artem Redchych developed CAREFUL-Bench for measuring intermediate tool effects. The exchange studies compare parser receipts with database state. Saibo Geng, Martin Josifoski, Maxime Peyrard and Robert West studied grammar-constrained decoding, a related method for controlling output structure. [CAREFUL-Bench](https://arxiv.org/abs/2611.02978v2) · [Grammar-constrained decoding](https://aclanthology.org/2023.emnlp-main.674/)

Hua and colleagues studied how the scoring method affects apparent prompt sensitivity. Lior and colleagues developed ReliableEval for sampling across prompt variants. The review compares those methods with repeated decoding of one source edit. [Hua et al., 2025](https://aclanthology.org/2025.emnlp-main.1006/) · [Lior et al., 2025](https://aclanthology.org/2025.findings-emnlp.594/)

Joren and colleagues studied whether the supplied context is sufficient for a question. Their work informed our pre-answer support check. [Sufficient Context, ICLR 2025](https://research.google/pubs/sufficient-context-a-new-lens-on-retrieval-augmented-generation-systems-2/)

## Data and tools

- EleutherAI’s Language Model Evaluation Harness documents conditional continuation likelihood and greedy agreement. The journal experiment uses these ideas for its optional per-token comparisons. [Pinned model interface](https://github.com/EleutherAI/lm-evaluation-harness/blob/v0.4.7/docs/model_guide.md#interface)

- Exgentic’s `agent-llm-traces` dataset supplied the recorded retail sessions for the importer comparison. The [sample manifest](examples/retail-sample.manifest.json) pins the dataset revision and documents session selection. The policy excerpt in [retail-annotations.json](examples/retail-annotations.json) comes from that dataset and is distributed under [CDLA Permissive 2.0](LICENSES/CDLA-Permissive-2.0.txt). [Exgentic dataset card](https://huggingface.co/datasets/Exgentic/agent-llm-traces)
- The retail sessions come from the τ²-Bench benchmark, by Victor Barres, Honghua Dong, Soham Ray, Xujie Si, and Karthik Narasimhan. [τ²-Bench paper](https://proceedings.mlr.press/v306/barres26a.html)
- The exchange walkthrough reconstructs the order, product, and confirmation checkpoint from Exgentic’s retail session `5b9274b3192a_03b2d919`. The two hold messages, replay prompts, and authorization check are NexusWeave test additions. [Pinned dataset and license](https://huggingface.co/datasets/Exgentic/agent-llm-traces/blob/70036b93a04e61b0ea2706a68b962f4f26774587/README.md)
- The retail reference comparison uses `agentpile` as a trace viewer. [agentpile](https://github.com/yzhao062/agentpile)
- The saved local replay examples use Liquid AI’s LFM2.5-1.2B-Instruct model through MLX LM. The repository ships synthetic requests and recorded trial outcomes for these examples. [Liquid AI model card](https://huggingface.co/LiquidAI/LFM2.5-1.2B-Instruct), [MLX LM](https://github.com/ml-explore/mlx-lm)
- The cross-runtime experiment also uses the Qwen team's Qwen2.5-0.5B-Instruct checkpoint through Transformers and PyTorch. The repository includes the measured reports and synthetic inputs. [Pinned Qwen model card](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct/tree/eaa56b503cc0a8a4d15de1dd8bd2a7e95a716be2), [Transformers](https://github.com/huggingface/transformers), [PyTorch](https://github.com/pytorch/pytorch)
- The optional context scorer uses Sentence Transformers' Apache-2.0 MiniLM cross-encoder, trained on SNLI and MultiNLI. IHEval provides related evaluation work on instruction hierarchy under conflict. [Pinned MiniLM model card](https://huggingface.co/cross-encoder/nli-MiniLM2-L6-H768/tree/b95119ce93d3e065de6214e38cd4a97b0f2f2c6d) · [SNLI](https://aclanthology.org/D15-1075/) · [MultiNLI](https://aclanthology.org/N18-1101/) · [IHEval](https://aclanthology.org/2025.naacl-long.425/)

The public passage-edit experiment uses the multi-document QA data released by Liu et al. and adapts the distribution-based source ranking studied by Li et al. NQ-Open questions and annotations retain the dataset’s CC BY-SA 3.0 license. The source index identifies the Wikipedia contributors’ articles used for each question, including passages that reappear in saved model answers. [Data notices and article index](examples/public-qa/data-credits.md) [Lost in the Middle data](https://github.com/nelson-liu/lost-in-the-middle/tree/29b8a6d042ce29abccee3db1a73171a107d7e6af) · [ARC-JSD](https://arxiv.org/abs/2505.16415)

The review also compares this work with PECoRe by Gabriele Sarti and colleagues and MIRAGE by Jirui Qi and colleagues. Both use changes in token predictions to study context reliance. [PECoRe](https://gsarti.com/publication/pecore/) · [MIRAGE](https://aclanthology.org/2024.emnlp-main.347/)

The passage-omission experiment evaluates a specified abstention before generation. Rajpurkar and colleagues studied abstention on human-written unanswerable questions in SQuAD 2.0. The transfer experiment uses their SQuAD 2.0 development labels. The authors distribute the data under CC BY-SA 4.0. The saved results identify the questions and paragraphs by ID and digest. [Dataset and license](https://rajpurkar.github.io/SQuAD-explorer/) · [Transfer experiment](examples/public-qa/support-review/transfer/README.md) [SQuAD 2.0](https://aclanthology.org/P18-2124/) · [Paired omission study](examples/public-qa/annotation-gap.md)

The dashboard adapts the force-directed graph layout by Thomas Fruchterman and Edward Reingold to position the nodes in a bounded overview. Position has no role in the attribution scores. [Graph drawing by force-directed placement](https://doi.org/10.1002/spe.4380211102)

Qwen-Agent’s Nous tool parser and registered tool interface supplied an independent execution path for the exchange study. The replay uses the published framework with a saved-text transport and application-owned OpenTelemetry spans. [Qwen-Agent 0.0.34](https://pypi.org/project/qwen-agent/0.0.34/) · [Replay implementation](examples/exchange-approval/dispatch-study/framework/README.md)

Sierra Research’s τ-Bench leaderboard supplies the recorded agent dialogue and reservation lookups for the airline transfer study. The public task split, reference actions and tool signatures come from its pinned benchmark release. The checkout includes checkpoint identifiers, digests, and test results. Reproduction downloads the original data separately. The Exgentic airline census identifies the participant whose telemetry was available in that corpus. [Study and source manifest](examples/airline-transfer/README.md) · [Sierra leaderboard submission](https://github.com/sierra-research/tau2-bench/blob/c06b07dd7c4d4ec61ba6ff9bcdf0b15dd7ef36d4/web/leaderboard/public/submissions/claude-opus-4-5_sierra_2026-02-26/submission.json)

## Interoperability

The local stdio adapter uses the official Rust SDK for Model Context Protocol. [Rust MCP SDK](https://github.com/modelcontextprotocol/rust-sdk)

The embedded conflict view uses the official MCP Apps browser SDK. Its dependency licenses are included with the bundled view. [MCP Apps SDK](https://github.com/modelcontextprotocol/ext-apps), [Bundled JavaScript licenses](LICENSES/MCP-App-JavaScript.txt)

The dashboard uses the official Lit renderer and Basic Catalog for A2UI recommendation cards. [A2UI project](https://github.com/a2ui-project/a2ui) · [Bundled JavaScript licenses](LICENSES/A2UI-JavaScript.txt)

The importers follow trace and attribute formats published by OpenTelemetry, OpenInference, and LangSmith. [OTLP specification](https://opentelemetry.io/docs/specs/otlp/), [OpenInference semantic conventions](https://arize-ai.github.io/openinference/spec/attributes/semantic-conventions.html), [LangSmith run format](https://docs.langchain.com/langsmith/run-data-format)
